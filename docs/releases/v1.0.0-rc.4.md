# `v1.0.0-rc.4` release notes

> **Unofficial project.** unifi-cli is an independent community tool and is not affiliated with, endorsed by, or sponsored by Ubiquiti Inc. UniFi is a trademark of Ubiquiti Inc.

RC.4 supersedes RC.3 because final stable-note verification found that the
checked-in `v1.0.0` notes still named RC.2 as the matching source candidate.
RC.4 corrects that reference before unchanged-source stable promotion.

This candidate changes documentation only. It changes no executable,
controller API, command surface, schema, compatibility, or mutation behavior
from RC.3. Stable writes remain limited to the seven official DNS policy types.
Every non-DNS write remains experimental, and no fixed-IP or other non-DNS live
write is claimed.

## Qualification

The RC.4 source must pass formatting, unit, schema, documentation, coverage,
release-contract, module, race, vulnerability, six 30-second fuzz, release-host
performance, native-keyring, and hosted operating-system gates. Publication
must independently build and compare all six native archives, execute each on
its native hosted runner, publish matching SHA-256 checksums and CycloneDX
SBOMs, and attach provenance attestations.

On the designated darwin/arm64 release host, the three-sample medians were
16,049,208 ns and 5,451,280 bytes for the 10,000-item collection benchmark,
83,668,375 ns and 40,740,112 bytes for the 1,000-detail-read benchmark, and
0.00 seconds for warm help. All release-host performance budgets passed.

The controller-facing and executable source is unchanged from RC.3. The
controller qualification passed all configured read-only checks on UniFi
Network 10.5.67 and disabled create/update/delete lifecycles for A, AAAA,
CNAME, MX, TXT, SRV, and forwarded-domain policies. It restored the exact empty
DNS baseline. The local controller required the explicit insecure-TLS
exception for its self-signed certificate; verified TLS remains the default.

## Install after publication

```bash
go install github.com/noahjenkins/unifi-cli/cmd/unifi@v1.0.0-rc.4
unifi --version
unifi version --json
```

Both version interfaces must report `v1.0.0-rc.4` for the tagged source
install. Its `commit` and `build_date` remain `unknown`. Verified release
archives carry authoritative version, commit, build date, checksums, SBOMs,
and provenance.

The account-controlled tag is unsigned. Confirm it resolves to the protected
main commit shown by the GitHub release before installation.
