# `v1.0.0-rc.3` release notes

> **Unofficial project.** unifi-cli is an independent community tool and is not affiliated with, endorsed by, or sponsored by Ubiquiti Inc. UniFi is a trademark of Ubiquiti Inc.

RC.3 supersedes RC.2 because post-publication source-install verification
found that `unifi --version` reported `dev`. The detailed
`unifi version --json` command already recovered the correct tagged module
version. RC.3 applies the same effective build information to both interfaces.

Apart from this build-information output fix, this candidate changes no
controller API, command surface, schema, compatibility, or mutation behavior
from RC.2. Stable writes remain limited to the seven official DNS policy types.
Every non-DNS write remains experimental, and no fixed-IP or other non-DNS live
write is claimed.

## Qualification

The RC.3 source must pass formatting, unit, schema, documentation, coverage,
release-contract, module, race, vulnerability, six 30-second fuzz, release-host
performance, native-keyring, and hosted operating-system gates. Publication
must independently build and compare all six native archives, execute each on
its native hosted runner, publish matching SHA-256 checksums and CycloneDX
SBOMs, and attach provenance attestations.

On the designated darwin/arm64 release host, the three-sample medians were
14,569,125 ns and 5,417,168 bytes for the 10,000-item collection benchmark,
71,177,125 ns and 34,443,512 bytes for the 1,000-detail-read benchmark, and
0.00 seconds for warm help. All release-host performance budgets passed.

The controller-facing source is unchanged from the qualified RC.2 behavior.
That qualification passed all configured read-only checks on UniFi Network
10.5.67 and disabled create/update/delete lifecycles for A, AAAA, CNAME, MX,
TXT, SRV, and forwarded-domain policies. It restored the exact empty DNS
baseline. The local controller required the explicit insecure-TLS exception
for its self-signed certificate; verified TLS remains the default.

## Install after publication

```bash
go install github.com/noahjenkins/unifi-cli/cmd/unifi@v1.0.0-rc.3
unifi --version
unifi version --json
```

Both version interfaces must report `v1.0.0-rc.3` for the tagged source
install. Its `commit` and `build_date` remain `unknown`. Verified release
archives carry authoritative version, commit, build date, checksums, SBOMs,
and provenance.

The account-controlled tag is unsigned. Confirm it resolves to the protected
main commit shown by the GitHub release before installation.
