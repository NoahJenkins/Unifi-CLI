# `v1.0.0` release notes

> **Unofficial project.** unifi-cli is an independent community tool and is not affiliated with, endorsed by, or sponsored by Ubiquiti Inc. UniFi is a trademark of Ubiquiti Inc.

`v1.0.0` is the first stable local-controller release. It has the same source
contract as the qualified `v1.0.0-rc.4` candidate and targets UniFi Network
10.4.57 or newer.

## Stable surface

- Official typed reads for sites, devices, clients, networks, WiFi, ports,
  modern firewall zones/policies/traffic lists, all DNS policies and resolvers,
  LAGs, MC-LAG domains, switch stacks, RADIUS profiles, and system health.
- Official exact create/update/delete for all seven DNS policy types.
- A checked-in schema-v1 JSON contract with no raw controller payload mode.
- Native API-key storage, verified TLS by default, plan-first mutations,
  immutable target binding, drift checks, no ambiguous write retries, and exact
  observable verification.

All non-DNS writes remain experimental because they have no disposable
sacrificial-controller qualification. Classic firewall rulesets and
switching/RADIUS writes are unsupported.

## Qualification

The unchanged release source passed the complete local and hosted gate set.
UniFi Network 10.5.67 passed all configured read-only checks and disabled,
uniquely named create/update/delete lifecycles for all seven official DNS
policy types. Every lifecycle deleted only its captured ID, and the final DNS
collection exactly matched the empty baseline. The local controller used the
documented explicit insecure-TLS exception for its self-signed certificate;
verified TLS remains the default. No fixed-IP or other non-DNS live write was
run or claimed.

For SRV policies, `--name` is the base domain. `--service` and `--protocol`
provide the underscore-prefixed SRV labels separately.

## Install

```bash
go install github.com/noahjenkins/unifi-cli/cmd/unifi@v1.0.0
unifi --version
unifi version --json
```

Confirm `v1.0.0` resolves to the protected-main release commit shown by the
GitHub release. The account-controlled tag is not cryptographically signed.
Downloaded archives must match `checksums.txt`; each archive also has a
CycloneDX SBOM and GitHub provenance attestation. See the [README](../../README.md),
[compatibility contract](../compatibility.md), and
[security policy](../../SECURITY.md) before use.

The tagged source install reports `v1.0.0`, but its `commit` and `build_date`
remain `unknown`. Verified archives carry the authoritative full build metadata
with their checksums, SBOMs, and provenance.
