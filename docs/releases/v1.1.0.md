# `v1.1.0` release notes

> **Unofficial project.** unifi-cli is an independent community tool and is not affiliated with, endorsed by, or sponsored by Ubiquiti Inc. UniFi is a trademark of Ubiquiti Inc.

`v1.1.0` has the same source contract as the qualified `v1.1.0-rc.1`
candidate and targets UniFi Network 10.4.57 or newer. See the
[`v1.1.0-rc.1` release notes](v1.1.0-rc.1.md) for the complete change and
qualification record, and [`CHANGELOG.md`](../../CHANGELOG.md) for every entry.

## Summary

- The stable surface is unchanged from `v1.0.0`: official typed reads and
  exact create/update/delete for all seven official DNS policy types.
- New local tools: named non-secret controller profiles and `unifi doctor`.
- New experimental commands: known-client fixed-IP inventory and offline
  set/clear, exact-filter firewall policy create (source IP or subnet,
  destination IP, TCP port), WLAN access-point selection, and network mDNS
  forwarding update.
- Official HTTP 400 validation errors return sanitized `code` and `message`
  fields.
- Built with Go 1.27.3. macOS binaries require macOS 13 Ventura or later.

All non-DNS writes remain experimental because they have no disposable
sacrificial-controller qualification. Classic firewall rulesets and
switching/RADIUS writes are unsupported.

## Install

```bash
go install github.com/noahjenkins/unifi-cli/cmd/unifi@v1.1.0
unifi --version
unifi version --json
```

Confirm `v1.1.0` resolves to the protected-main release commit shown by the
GitHub release. The account-controlled tag is not cryptographically signed.
Downloaded archives must match `checksums.txt`; each archive also has a
CycloneDX SBOM and GitHub provenance attestation. See the
[README](../../README.md), [compatibility contract](../compatibility.md), and
[security policy](../../SECURITY.md) before use.

The tagged source install reports `v1.1.0`, but its `commit` and
`build_date` remain `unknown`. Verified archives carry the authoritative full
build metadata with their checksums, SBOMs, and provenance.
